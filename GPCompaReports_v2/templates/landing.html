    What this database measures

    Every receptor here is compared in two predicted conformations. The number we report is how much each pair of residues touches in one state versus the other.

    RRCS scores how strongly two residues are in contact in one structure. Comparing the same pair across an active and an inactive model gives ΔRRCS, the change in that contact between states.

    Red marks contacts that are stronger in the active state. Blue marks contacts that are stronger in the inactive state.

    Each receptor page ranks the contact pairs we detected by how much they change, marks which of them exceed that receptor's own threshold, and shows where those changes sit in the structure.

    About GPCompaRe

    GPCompaRe is a database of active-inactive residue-residue contact changes across {{ total_gpcrs }} human Class A G protein-coupled receptors. For each receptor, active and inactive AlphaFold multistate models (del Alamo et al., 2022) were compared using Residue-Residue Contact Scores (RRCS), producing a ΔRRCS value for each detected contact pair.

    Each receptor report maps contact-score changes to transmembrane segments, GPCRdb generic positions, residue-level summaries, gnomAD missense variants, AlphaMissense predictions, and conservation annotations. The database is designed for both receptor-level inspection and cross-GPCR comparison of recurrent activation-associated contact changes.

    Positions and contact pairs highlighted by GPCompaRe should be interpreted as model-derived structural candidates, not direct experimental evidence of function.
